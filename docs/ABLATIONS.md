# 消融的精确定义

## 公共条件

六个方法都用同一 Flat run1+run2 顺序、762 源帧、191 个融合/分割帧、640×480、米制位姿、2.5 cm TSDF、block resolution 4、`block_count=200000`、相同 191 组 mask/1024 维特征、同一 FCGF 权重、随机种子 27。GT 仅用于最后评分。

Full 家族统一使用 disjoint-pair merging，最终额外全局 merge 关闭，AABB carving 关闭，depth shrink 关闭，多分辨率和 online-fine-evidence 关闭。原始 Baseline 使用独立 `baseline/` 原版建图代码，不是简单把 Full 的删除开关关掉。

## 方法表

| CLI 名称 | 含义 | H 确认 | 删除 | ObsRefine |
|---|---|---|---|---|
| `baseline` | 原始 OnlineAnySeg | 无 | 无 | 无 |
| `full` | 当前 Full(H) | 双来源首轮可提前确认，否则两次独立合格观测 | 整实例，保留共享节点 | 开 |
| `f0` | 去掉变化检测/删除 | 不运行变化模块 | 关闭 | 开 |
| `o0` | 去掉观测细化 | 同 Full | 同 Full | 关 |
| `l` | 改用局部删除 | 同 Full | 仅矛盾参考表面所在 cube 的专属角点；不强制整实例退休 | 开 |
| `t1-any` | 一处有效拥有像素矛盾即确认 | 单点即时规则，见下文 | 整实例，保留共享节点 | 开 |

实际命令由 `configs/ablations.json` 决定。`detector_H/F0/O0/L.json` 保持同一基础参数；差异由入口、`--correction`、`--observation-refine` 与 L/T1 适配器实现。F0 是 `--correction off`，不能把缺失删除档案的 Full 当作 F0 来计 D=0。

## Full(H) 的确认规则

基础 `confirm_observations=2`。对同一个 candidate、同一当前观测，在 `hits==0` 的首次/强支持重置后的首次状态，如果 **深度矛盾点/全部冻结参考点 ≥0.2 且 RGB 矛盾点/全部冻结参考点 ≥0.2**，本轮有效确认次数临时变为 1。两个来源可以来自不同参考点；不是每个点必须同时有两类矛盾。其他情况下仍需要两次合格、独立观测，来源可以相同或不同。

提前确认只改变确认次数，不绕过基本有效性、矛盾比例、参考测试点数、覆盖率、位姿独立性、强支持重置/取消等检查。核心参数：

| 参数 | 值 |
|---|---:|
| 深度绝对/相对容差 | 0.08 m / 0.01 |
| 地图最小权重 / 实例最小权重 | 3 / 5 |
| 最少有效拥有像素 | 80 |
| 矛盾比例 | 0.5 |
| 参考点数量 | 100..6000 |
| 当前最少测试参考点 | 100 |
| 累积已测试参考比例 | 0.12 |
| 累积矛盾参考比例 | 0.2 |
| 观测帧间隔 | 至少 5 |
| 平移/旋转独立性参数 | 0.02 m / 3° |
| 强支持比例 / 取消次数 | 0.6 / 2 |
| candidate 冷却 / 最大数 | 30 帧 / 256 |
| RGB MAD 系数、阈值上下界 | 4 / 8..50 |

完整参数以 JSON 为准，状态机见 `feng_remove_detection.py`，H 覆盖层见 `adapters/hybrid_confirmation.py`。确认后先沿 raw instance lineage 解析当前后代，再进行共享节点保护和删除，避免直接把过期 slot 当作当前实例。

## L：局部范围不是“重新跑相同 Full 删除事件”

`adapters/local_erasure.py` 先沿相同 lineage 找到当前实例，将候选矛盾参考表面映射到其八个 cube 角点，与原始专属节点集合求交，再调用**同一个实际 TSDF eraser 和证据记录器**。其余实例共享的节点继续保留；目标尚存的支持不会被强制整实例退休。完全空的实例仍可被公共 eraser 清理。

L 与 Full 从头独立在线运行。删除范围改变后，后续地图和观测会不同，因此不能要求二者删除事件逐帧完全相同。

## T1-any 与“把确认次数设为 1”不同

`adapters/immediate_confirmation.py` 保留每帧/每点有效性、可靠 ownership、RGB/深度矛盾分类与整实例 eraser，但移除四个 candidate 实例级聚合准入块。只要有一处有效、owned 的像素矛盾就立即确认。原冻结 detector 源码 SHA256 在安装适配器时检查，动态变换源会保存到输出目录。

这比单纯 `confirm_observations=1` 更激进，不应把旧 T1(T1-threshold) 与当前 T1-any 混为一谈。它不会因为 GT 预期分数低而改阈值。
