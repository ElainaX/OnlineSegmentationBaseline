# ITSubmap 六场景接线与对照

本轮只连接已有 IG sparse-disjoint 实例关联和 IndependentTSDFStore。
不启用矛盾检测/纠错、深度收缩、Carving-AABB、旧 submap 匹配或几何 fallback。

## 数据流与所有权

共享 TSDF 仍提供原 IG 的可见体素、overlap 和 FCGF 查询。实例身份完全由未改动的
SparseDisjointSubmapManager 决定；独立几何不向关联算法反馈，不增加 GT 匹配、重识别或新合并规则。

一个现有 merge 周期内缓存 RGB-D、位姿和已接受 mask 的 append-only global ID。
周期结束时，按照**当时**已知的 IG 合并关系，把同一实例在这一周期内的观测融合进一个独立 TSDF。
同帧属于同一片段的多个 mask 先取并集，一帧只融合一次。未归属已接受 mask 的像素在独立
background 片段中融合，避免最终最近邻评估只剩有标签点而扩大实例范围。

被 IG 剔除的不同 mask 不因都映射到 -1 而融合；它们成为独立的无标签 orphan 片段。
所有片段固定世界坐标锚点，保证体素格一致；每周期冻结、落盘保存完整 TSDF/观测 mask，释放其 GPU 内存。
后续全局身份合并只用 global ID 更新片段引用，不改写旧片段数值，不删除旧几何。
因此本轮是有一个 merge 周期缓冲延迟的因果流程，不是根据最终轨迹离线重新融合整个序列。

## 输出与评估

IT 的 final.ply 完全来自独立片段表面，包括无标签背景和被 IG 剔除身份的几何。
以同样的世界体素分辨率归并导出点，仅用于公共点索引；各片段 TSDF 文件不变。
同一导出点可保留多个实例的支持，沿用 IG return_list 导出路径的 mask 排序及 DBSCAN
参数（eps=0.1 m、min_samples=1、最大连通簇点数>200），不顺手修复原有导出行为。
使用相同身份权重阈值和最小实例点数25。类无关 AP 使用原 baseline 的评估脚本及原 GT。

**实现边界：**首次独立 LocalTSDF 提取阈值为1；IG共享Open3D提取默认值3。随后确认接口使用严格大于比较，IT修正为0.5，保留至少一次观测。首次结果完整保留。
局部片段观测权重不跨体积汇总。这是重建流程的实质差别，不能宣称本实验“仅改变存储而数学完全等价”。
局部融合使用 float 米深度；原共享融合使用 uint16 的 depth_scale 量化深度。
片段提取、世界格导出重采样也可能影响表面覆盖与精度，均需结合 AP 解释。
独立 TSDF 使用 IG 接受的原始二维 mask 区域及其深度，不再用共享 TSDF 的实例体素
坐标集合裁剪局部几何；最终实例支持来自片段身份。IG 的三维支持筛选与此也存在区别。

同时将本次同进程的 IG 导出保存在 ig_audit 中，独立计算 AP。
它不是 IT 的 fallback，而是用来检查关联过程是否仍与历史 IG 对照一致。

## 运行配置

六场景均25mm。ScanNet scene0050_00 / scene0549_00 为10帧间隔；
3RScan pair01 / pair03 / pair04 为2帧间隔，pair02 为5帧间隔。
建图与分割间隔一致，原始输入/配置文件保持一致。seed=27；无额外 final merge。
保存原配置哈希、完整采样帧ID、子图分辨率、commit、模块开关、片段清单与身份引用。

记录主循环耗时、局部融合耗时、独立片段落盘耗时、导出耗时、峰值单片段体素属性容量。
主循环时间包含冻结片段的持久化，硬盘IO不是纯计算时间。GPU 为共享 A100，历史耗时不能
直接用于声称严格加速比。与历史 IG 的 AP 差和同进程 IG audit 的 AP 差分别核对。

## 检查

新增5项 adapter 检查与原6项独立几何检查通过，包括：孤立 mask 不误归为同一身份、
身份重编号/非法拆分检测、导出体素索引对重叠支持的保留、因果周期融合与保存恢复。
先进行61帧接线检查（不是 benchmark），通过后再跑完整六场景。

真实数据检查曾在独立 TSDF 的第三次融合遇到 CUDA misaligned address。将当前因果窗口
的全部块坐标预计算并在融合前一次性预分配后，61帧检查及全部10项测试通过。
原 IG 单独运行未出现该异常。接线代码不再依赖已填充局部 hashmap 的中途扩容。
这属于实现修复，没有改变 TSDF 输入样本、权重、关联公式或阈值。

正式运行代码提交：ae2e92f；分支 it-submap-disjoint-eval-20261007。

### 为什么要保留单观测表面

实测单次观测的合成平面：threshold=1提取0点，threshold=0.5提取2401点；
两次观测时，threshold=1提取2401点、threshold=2提取0点，证明接口是严格大于。
首次很多短片段只观测一次，体素已保存但没有表面输出。0.5只是恢复这些已有几何的导出，
没有增加纠错、补全或关联模块。初次结果与修正结果均保留在Excel，不能择优混用。

### 核对范围与结论限制

- 两个ScanNet场景的最终轨迹中原始mask分组与历史IG完全相同。
- 3RScan的轨迹分组没有完全复现历史，pair02/03/04的IG AP也有差异。
  同一源配置和代码规则不等于逐位确定的轨迹输出，当前尚未隔离复现差异原因。
- 因此判读独立几何影响，应优先同时看同次运行IG对照；历史对照按用户要求保留。
- 0549改善明显，0050下降。pair01仍有AP/AP25下降，pair03 AP25下降；
  pair04较历史AP略升、较同次IG AP略降。不能据此宣称所有场景都有收益。
- 这是独立重建整个流程的对照，包含局部观测、表面提取、二维支持与导出采样差异。
  尚不是只改变内存存储位置的等价实验。
